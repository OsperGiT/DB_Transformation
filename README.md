## Проектная реализация трансформации 3NF в DATA VAULT
### Тема: Система должна описывать порядок подготовки к экзамену, предполагающий получение отличной оценки
- #### DB_3NF - это простая, написанная с нуля, база данных, удовлетворяющая третьей нормальной форме
- #### DB_DV - это преобразованная структура третьей нормальной формы в DATA VAULT структуру, на основе DB_3NF
